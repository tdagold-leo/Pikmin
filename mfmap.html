定位權限被封鎖時怎麼開啟

電腦版 Chrome / Edge

  1. 點網址列左邊的鎖頭、調整圖示或資訊圖示。
  2. 找到「位置」。
  3. 改成「允許」。
  4. 重新整理頁面。

如果瀏覽器出現「管理」按鈕，也可以點進去把此網站的位置權限改回允許。

手機 Safari

  1. 開啟 iPhone「設定」。
  2. 找到「Safari」。
  3. 找到「位置」。
  4. 改成「詢問」或「允許」。
  5. 回到網站重新整理。

也可以在 Safari 網址列左邊點 aA 或網站設定，查看單一網站的位置權限。

手機 Chrome / Android

  1. 點網址列左邊的鎖頭或網站資訊。
  2. 進入「權限」。
  3. 找到「位置」。
  4. 改成「允許」。
  5. 重新整理頁面。
